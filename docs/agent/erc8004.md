## What is ERC-8004?

ERC-8004 establishes a standard on EVM networks for registering autonomous agents as on-chain identities with cryptographically verifiable capabilities:

1. Verifiable Agent Ownership: Links the autonomous agent software to an authenticated creator and primary operational wallet.
2. Attribution Tracking: Every on-chain transaction initiated or coordinated by Sivan carries the attribution tag celo_bafcc2e56bd7, ensuring transparent auditability on block explorers and 8004scan.
3. Machine-to-Machine Trust: External AI agents, smart contracts, and dApps can query the Celo ERC-8004 registry to verify Sivan AI credentials before delegating settlement authority.
